Easy Kit

You ask for a change. Easy Kit plans it, builds it, checks it, and leaves the merge to you.

Read the docs

The journey

  1. Your step You ask Say what you want, in plain words.
  2. Easy Kit It plans A written plan comes first.
  3. Easy Kit Agents build Each agent works in its own copy of the code.
  4. Easy Kit It checks Tests and a review run before anything ships.
  5. Your step You merge You read the result and merge it. Easy Kit never merges for you.

Two paths

  1. Small or big job? Easy Kit picks and tells you. You can override it.
    • small
      minimal trackFast pathEasy Kit does the work itself, test first, and ends with a short note. Example: fix a typo.
    • big
      extended trackFull pathA full plan, agents that build, full checks, then you merge. Example: add a login page.

What it stops

Scripts enforce these, not the model.

  • ifThere is no written plan
    blockedNo agent starts
  • ifNo test and check are on record
    blockedNo push, no merge
  • ifA secrets file is touched
    asks youYou confirm first
  • ifA job runs too many steps
    blockedThat call stops

These checks run on Claude Code only. Codex and Cursor get the rules, not the checks.
