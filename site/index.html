The full journey

  1. Your step You ask Say what you want.
  2. Easy Kit It plans A written plan comes first.
  3. Easy Kit Agents build Agents work in separate copies.
  4. Easy Kit It checks Tests and review run before shipping.
  5. Your step You merge You review. Easy Kit merges only when you ask.

Two paths

  1. Small or big job? Easy Kit picks and tells you. You can override it.
    • small
      minimal trackFast pathTest first, then a short note. Example: fix a typo.
    • big
      extended trackFull pathFull plan, agents build, full checks. Example: add a login page.

What it stops

Scripts enforce these, not the model.

  • ifA task has no written plan
    blockedIts agent does not start
  • ifAn open task has no check on record
    blockedNo push, no merge
  • ifA secrets file is about to change, outside the plan
    asks youYou confirm first
  • ifA task runs too many steps
    blockedThat call stops

These checks run on Claude Code only. Codex and Cursor get the rules, not the checks.
